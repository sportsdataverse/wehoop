# Internal: GET a Basketball-Reference WNBA page and return the body text

Internal: GET a Basketball-Reference WNBA page and return the body text

## Usage

``` r
.bref_wnba_text(path)
```

## Arguments

- path:

  Page path beginning with `/` (e.g.
  `"/wnba/years/2024_per_game.html"`).

## Value

The response body as a character string.
