# wehoop: Access Women's Basketball Play by Play Data

A utility for working with women's basketball data. A scraping and
aggregating interface for the WNBA Stats API <https://stats.wnba.com/>,
ESPN's women's college basketball and WNBA statistics, NCAA women's
basketball statistics, Fox Sports, Basketball-Reference, Her Hoop Stats,
Barttorvik and the WNBA referee assignments published by the NBA
officiating site. It also reads international women's basketball: FIBA
competitions, Spain's FEB leagues, Germany's DBBL, Japan's W League,
Australia's WNBL, the Turkish Basketball Federation leagues and leagues
served by Genius Sports and Sportradar Atrium. Loaders read pre-scraped
play-by-play, box score, schedule and model datasets from the
'SportsDataverse' data releases. It provides users with the capability
to access the game play-by-plays, box scores, standings and results to
analyze the data for themselves.
