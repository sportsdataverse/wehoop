# **Get ESPN Women's College Basketball Event Officials**

**Get ESPN Women's College Basketball Event Officials**

**Get ESPN Women's College Basketball Event Officials**

## Usage

``` r
espn_wbb_event_officials(event_id, ...)
```

## Arguments

- event_id:

  ESPN event/game identifier (character or numeric).

- ...:

  Additional arguments; currently unused.

## Value

A tibble with one row per official assigned to the game.

|               |           |
|---------------|-----------|
| col_name      | types     |
| event_id      | character |
| official_id   | character |
| full_name     | character |
| display_name  | character |
| position_id   | character |
| position_name | character |
| position_type | character |
| order         | integer   |
