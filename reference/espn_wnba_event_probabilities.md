# **Get ESPN WNBA Event Win Probabilities**

**Get ESPN WNBA Event Win Probabilities**

**Get ESPN WNBA Event Win Probabilities**

## Usage

``` r
espn_wnba_event_probabilities(event_id, limit = 200, ...)
```

## Arguments

- event_id:

  ESPN event/game identifier (character or numeric).

- limit:

  integer. Maximum number of probability rows to return. Defaults to
  `200`. Pagination is handled internally.

- ...:

  Additional arguments; currently unused.

## Value

A tibble with one row per play-level win-probability entry.

|                       |           |
|-----------------------|-----------|
| col_name              | types     |
| event_id              | character |
| sequence_number       | character |
| play_id               | character |
| period                | integer   |
| clock                 | character |
| home_win_percentage   | numeric   |
| away_win_percentage   | numeric   |
| tie_percentage        | numeric   |
| secs_to_end_of_period | numeric   |
| secs_to_end_of_game   | numeric   |
